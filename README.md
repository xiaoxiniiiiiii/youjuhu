# YOUJUHU Home Living

React + Vite 家居生活百货 storefront demo，采用纯色、暖中性色与项目内独立商品图形构成原创视觉。

## Run

```bash
npm.cmd i
npm.cmd run dev
npm.cmd run build
```

## Included

- 5 个商品类目，每类 10 个商品，价格约 $79–$189。
- `Add to cart` 自动打开购物车侧栏；`Buy Now — $price` 直接进入结算页。
- 结算页包含 PayPal、Visa、Credit card 选项展示。
- 页脚包含 About us、Shipping policy、Payments/returns/refunds、Order tracking、Terms of Service（17 部分）、Privacy policy、DMCA。
- 后台演示入口：`Admin demo`。
